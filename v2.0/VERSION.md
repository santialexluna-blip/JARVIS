# JARVIS v2.0 — Arquitectura expandida

Esta carpeta marca la siguiente generación del proyecto sin romper el núcleo v1.x.

Capas previstas:
- herramientas seguras
- búsqueda web
- memoria avanzada
- interfaz gráfica
- automatización de escritorio
- voz y activación

Las capacidades sensibles deben permanecer explícitas, auditables y con confirmación cuando corresponda.
