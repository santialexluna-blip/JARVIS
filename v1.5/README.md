# JARVIS v1.5 — Memoria avanzada

Añade sesiones aisladas con historial reciente por `session_id`.

## Capacidades
- Crear y recuperar sesiones.
- Guardar mensajes por rol.
- Recuperar solo el contexto reciente.
- Eliminar una sesión completa.

La memoria de v1.5 se mantiene desacoplada para integrarla después con el núcleo de JARVIS sin romper la memoria persistente de v1.1.
