# JARVIS — plan de versiones

## v1.1
Núcleo modular, memoria persistente, contexto, herramientas y proveedor IA intercambiable.

## v1.2
Voz: STT/TTS y activación por palabra clave.

## v1.3 — INSTALADA
Integración segura con Windows mediante herramientas explícitas: estado, Notepad, Calculadora y carpetas.

## v1.4
Búsqueda web y recuperación de información.

## v1.5
Memoria avanzada, perfiles de contexto y sesiones.

## v2.0
Arquitectura completa del asistente: voz + herramientas + web + memoria + automatización + interfaz.

## v2.1+
HUD/escritorio, plugins, observabilidad y nuevas herramientas.

> Las capacidades sensibles deben ser explícitas, auditables y limitarse a operaciones seguras.
