# JARVIS v1.3 — Windows seguro

Añade integración básica con Windows mediante herramientas explícitas.

## Capacidades
- Detectar el sistema operativo.
- Abrir Notepad.
- Abrir Calculadora.
- Abrir una carpeta existente.

No se permite ejecutar comandos arbitrarios, PowerShell libre ni cadenas proporcionadas directamente por el usuario.
